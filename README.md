## Compiling and Running

To compile the program, use the provided `Makefile`:

```bash
make
```

To run the program with a CSV file:

```bash
./etsy_sales_analyzer <your_csv_file.csv>
```

## Features

The program offers the following analysis options:

*   View unique shipping countries
*   View unique shipping states
*   View unique shipping cities
*   View top N shipping countries
*   View top N shipping states
*   View top N shipping cities

## Input File Format

The program expects a CSV file with tab-separated values. The following columns are required:

*   `Ship Country`
*   `Ship State`
*   `Ship City`
